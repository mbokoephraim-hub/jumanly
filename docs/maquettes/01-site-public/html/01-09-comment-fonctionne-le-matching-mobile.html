Comment fonctionne le matching

Sur Jumanly, l'IA recommande et l'humain décide. Voici, en langage simple, comment nous calculons la compatibilité entre un talent et une offre.

Pourquoi ?

1. Un score de 0 à 100

Pour chaque offre, nous comparons les besoins du recruteur à votre profil. Le résultat est un score de 0 à 100. Plus il est élevé, plus votre profil correspond à ce que l'offre demande.

0507085100

2. Huit critères, et seulement ceux-là

Le score additionne huit critères liés au poste :

les compétences requises ;
les compétences souhaitées ;
l'expérience ;
la localisation et le télétravail ;
le type de contrat ;
les langues ;
la formation ou le diplôme ;
la disponibilité.

3. Des poids choisis par le recruteur

Chaque critère compte pour une part du score. Le recruteur peut donner plus de poids à ce qui compte vraiment pour le poste. Ces poids sont affichés dans l'explication du score.

5. Un « Pourquoi ? » sur chaque score

Chaque score s'accompagne d'une explication : les critères remplis, ceux qui le sont en partie, les compétences manquantes, et les formations Jumanly qui peuvent combler l'écart.

6. Ce que nous n'utilisons jamais

Ces informations ne sont jamais prises en compte dans le score, ni dans aucune suggestion :

le genre ; l'âge ; la photo ; l'origine ; la religion ; la situation familiale ; l'état de santé.
Votre forfait Jumanly n'est pas pris en compte non plus : un profil Free est recruté au même titre qu'un abonné.

7. L'IA ne rejette personne

Le matching classe et explique. Il n'écarte aucune candidature. Si une offre fixe des critères éliminatoires (par exemple un diplôme exigé par la loi), ils sont affichés sur l'offre ; un candidat qui ne les remplit pas est signalé au recruteur, jamais rejeté automatiquement. Chaque décision est prise par une personne.

8. Vous pouvez contester

Si votre score vous semble faux, touchez « Signaler une erreur » sous l'explication. Une personne de l'équipe Jumanly vérifie le calcul et vous répond par e-mail.

Signaler une erreur

9. Vous gardez le contrôle

Vous pouvez désactiver le calcul de compatibilité dans vos paramètres. Vous pourrez toujours postuler ; le recruteur verra votre candidature sans score.
