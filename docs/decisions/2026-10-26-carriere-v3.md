# Carrière v3 : choix d'intégration (26/10/2026)

1. **Adresses.** Au téléphone, la page Carrière reste `/app/career/cv` (racine de l'onglet Carrière du
   Modèle B). La création passe par `/app/career/cv/nouveau?etape=depart|modele|orbi|import|trouve` ;
   une fois le CV créé, ses étapes vivent sur `/app/career/cv/[id]?etape=…`. L'ordinateur n'est pas
   touché.
2. **Orbi prépare.** Le CV est créé avec le modèle Moderne (gratuit) à partir du profil ; le résumé
   d'Orbi est une suggestion en attente, que la personne garde ou refuse sur Contenu (l'IA propose,
   l'humain décide). Sans IA ou sans crédit, le CV est créé quand même et le dit.
3. **Import d'une photo.** Lue seulement par le modèle d'IA (pas de lecture à règles d'une image) :
   l'option renvoie une erreur claire si l'IA n'est pas prête. L'image est réduite dans le
   téléphone avant l'envoi.
4. **Score et vérifications.** Le score reste celui des règles fixes (`cvScore`) ; les huit
   vérifications de l'aperçu sont aussi à règles fixes (`cvChecks`). « Corriger » ne reprend que ce
   qui est dans le profil (titre, compétences, langues) et ne rajoute jamais rien d'inventé.
5. **Coordonnées.** La ligne Coordonnées n'a pas d'interrupteur : nom et contact sont toujours sur le
   CV (l'e-mail se masque dans le menu du CV, comme avant).
6. **« Récents sur ce téléphone »** devient « Votre dernière lecture » : la dernière lecture en
   attente est en base, rien n'est gardé dans le téléphone.
7. **Écarts connus.** Projets, bénévolat et certificats ne sont pas des sections du modèle de CV
   (« + Section » propose celles qui existent) ; l'édition détaillée d'une section (`?partie=`) garde
   l'écran précédent.
8. **CV vide (27/10).** Le téléphone ne télécharge plus un CV vide : l'aperçu d'exemple est
   signalé et le PDF attend que le CV soit rempli. L'ordinateur garde son comportement.
9. **CV importé gardé (27/10).** Le CV est gardé sous forme structurée (relu par Orbi), pas le
   fichier d'origine : la base ne stocke pas encore les fichiers de CV. Il reste modifiable et
   exportable comme les autres.
