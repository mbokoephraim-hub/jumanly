- **5 crédits Orbi par mois pour le forfait gratuit** : assez pour essayer (une ou deux aides), modifiable
  dans l'admin. La migration ne touche pas une valeur déjà changée dans l'admin.
- **Seuil de 60 %** pour la phrase « profil peu rempli » au moment de postuler : c'est le palier « prêt »
  du parcours Carrière. La candidature part toujours (règle d'or 1).
- **Bulle d'Orbi : 5 secondes**, puis elle se cache jusqu'au prochain changement de page.
- **Étape « Votre métier » sur ordinateur** : on peut la passer, sans minimum de compétences ; pas d'import
  de CV à cette étape (il reste dans Carrière).
- **Démo** : seuls les comptes de démonstration du seed sont remplis, jamais les comptes créés par les tests.
