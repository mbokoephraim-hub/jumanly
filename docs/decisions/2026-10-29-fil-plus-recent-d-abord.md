# Fil « Pour vous » : la plus récente d'abord

Date : 29/10/2026. Décision d'Ephraïm.

Le classement « professionnel d'abord » du 22/10/2026 (`feed-rank.ts`) faisait passer une offre ou un auteur actif d'hier devant une publication faite à l'instant. Ephraïm veut que les nouvelles publications s'affichent toujours devant. « Pour vous » est désormais dans l'ordre chronologique inverse, comme les deux autres onglets. Le classement reste dans l'historique git s'il faut un jour le reprendre sous une autre forme.
