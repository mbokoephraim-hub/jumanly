# Admin v3 · étape 3 : Studio formations

- Le plan prévoyait que `support_agent` voie la galerie sans le bouton de création. Les droits
  d'Admin v2 sont gardés tels quels : Formations et Contenus restent réservés à `content_editor` et
  `platform_admin` (le support n'y a pas accès). Aucun droit n'est élargi sans demande.
- Les couvertures générées (sans image envoyée) ne servent que dans l'admin : la publication exige
  toujours une vraie image de couverture (`publishProblems`).
- Le modèle « Partir de zéro » garde l'attestation activée, comme l'ancienne création par titre.
