6 · L’attestation

Le modèle PDF, A4 paysage, généré pour chaque réussite. Tous les éléments de sécurité sont calculés à partir de son numéro et de sa signature numérique.

Numéro uniqueJMN-XXXX-XXXX, imprimé en haut, dans le micro-texte et dans le code QR.
Signature numériqueEmpreinte calculée par Jumanly sur le nom, la formation, le score et la date. Toute modification la rend fausse.
Signature dessinéeTracé généré à partir de l’empreinte : chaque attestation a le sien.
Fond guillochéRosace et bandes de lignes fines, calculées à partir de l’empreinte. Une photocopie les brouille.
Micro-texteUne ligne de 3,6 points tout autour du cadre, illisible sans zoom, qui répète le numéro.
Sceau d’originalité« Attestation validée · sceau d’originalité » autour du symbole Jumanly.
Code QROuvre la page publique de vérification : authentique, révoquée ou introuvable.
PDF verrouilléTexte non modifiable, métadonnées signées. La preuve reste la vérification en ligne.
